## Status possíveis
1. **Novo** — entrou no DM, ainda não respondeu
2. **Qualificado** — bot validou interesse
3. **WhatsApp** — passou para o closer
4. **Call agendada** — data marcada
5. **Call feita** — call realizada, aguardando decisão
6. **Vendido** ✅
7. **Perdido** — registrar motivo

## Motivos de perda (preencher quando perder)
- Preço
- Tempo (vai começar depois)
- Já tem consultor
- Achou que era outra coisa
- Sumiu (sem resposta)
- Outro

## Metas funil
- DM → WhatsApp: 70%+
- WhatsApp → Call: 40-60%
- Call → Venda: 25-40%
- DM → Venda total: 8-15%
